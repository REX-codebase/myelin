One file.
Two readers.

A ledger is a short text file of hard rules for one library at one version. Each rule is a pattern and the sentence that explains the fix. Your model reads it before it writes. A script runs it after.

The sentence tells the model what is wrong and what to write instead.

Every failure
carries its fix.

Lint prints the rule, the line and the sentence the model needs to repair the file. Run it again. It exits 1 on any violation, so CI can stop the merge.

What it won't do.

Myelin is deliberately small. These are its edges.

  • It reads text, not meaning.

    Rules are regular expressions. They catch stale names and patterns, not logic, types or intent. Keep your tests and your type checker.

  • Clean is not correct.

    A pass means no known-stale pattern was found. It does not mean the code runs.

  • Comments can trip it.

    A banned token inside a comment can fire a rule. A ledger can set comments skip to blank comments first; so far only three.js does.

  • Every ledger is pinned.

    Each targets one release and a research date. Check its = version line before trusting it on a newer major.

  • The lift is measured on three.js.

    The other eighteen ledgers have detection benchmarks but no agent runs yet.

  • It is narrow on purpose.

    The three.js ledger covers WebGPU and TSL, not WebGL-only projects. unless lifts a ban for a whole file, not one match. No globs or severities yet.

  • It only constrains output.

    A ledger cannot grant permissions, run commands or change instructions, and readers ignore any line that tries. Load ledgers only from sources you trust.

Get Myelin.

You need Node 18 or newer. The installer unpacks into your home folder, never uses sudo, and does not install Node for you. Run it again later to upgrade.

$ curl -fsSL https://raw.githubusercontent.com/REX-codebase/myelin/main/install.sh | sh

Then, inside a project, run myelin setup. It reads your package.json, copies the matching ledgers into .myelin/ and adds a short block to AGENTS.md or CLAUDE.md, so your agent runs the rules before it writes and lint after. If something looks wrong, myelin doctor will say what.
