Rule ledgers for AI-written code

Your AI learned last year's docs. Myelin teaches it this year's.

Myelin keeps AI-written code on the current version of your libraries. The model reads a plain-text rule file before it writes, and a script checks the output after. Zero dependencies.

How it works

Install, set up, ship.

  1. 01

    Install

    One command. Put the myelin command on your machine.

    curl -fsSL …/install.sh | sh
  2. 02

    Setup

    myelin setup detects the libraries in your project and wires their ledgers into AGENTS.md or CLAUDE.md.

    myelin setup
  3. 03

    Ship

    Your agent reads the rules before it writes. myelin lint checks the result and fails on stale code.

    myelin lint react,tailwind src/

In the terminal

It catches the stale API before it ships.

The usual failure is a call deprecated two releases ago that the model writes with full confidence. Each ledger rule is a pattern plus the fix that explains it. Lint runs the same rules the model was given.

Clean is not the same as correct. A pass means no known-stale pattern was found. Keep your tests.

FAQ

Questions, answered plainly.

Short answers about what Myelin installs, what it sends, and what it does not do.

Do I need Node?

Myelin is a Node.js program, so it needs Node 18 or newer to run. If you already have it, npx github:REX-codebase/myelin setup needs nothing else. Check with node -v.

What does it change on my machine?

The installer puts a myelin command on your PATH. myelin setup works in the project you run it in: it adds the matching ledgers and a short pointer in AGENTS.md or CLAUDE.md.

Is anything sent over the network?

The install step downloads Myelin from GitHub, once. Myelin itself makes no network calls. It reads your project and its bundled ledgers from disk and prints results to your terminal.

Does it replace tests?

No. Myelin reads text, so it catches stale names and patterns, not logic or types. Keep your tests and your type checker. A clean pass means no known-stale pattern was found, not that the code runs.

How do I uninstall?

macOS, Linux and WSL: curl -fsSL https://raw.githubusercontent.com/REX-codebase/myelin/main/install.sh | sh -s -- --uninstall

Windows PowerShell: & ([scriptblock]::Create((irm https://raw.githubusercontent.com/REX-codebase/myelin/main/install.ps1))) -Uninstall

If you installed with npm, Homebrew or Scoop, use npm uninstall -g myelin-ledger, brew uninstall myelin or scoop uninstall myelin.
