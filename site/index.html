Your AI learned last year's docs. Myelin teaches it this year's.

what it is

Models are trained on yesterday's documentation. They write new THREE.Clock(), ReactDOM.render, @tailwind base and a synchronous cookies() with total confidence. The code looks right, and then it breaks, or warns, or quietly ships a deprecated API.

Myelin is a checklist the model can read and a linter the machine can run, from the same plain-text file. Nineteen libraries ship in the box.

install

You need Node 18 or newer. That is the only requirement.

macOS, Linux, WSL · looks like yours
$ curl -fsSL https://raw.githubusercontent.com/REX-codebase/myelin/main/install.sh | sh
Windows PowerShell · looks like yours
PS> irm https://raw.githubusercontent.com/REX-codebase/myelin/main/install.ps1 | iex
Already have Node and want to install nothing
$ npx github:REX-codebase/myelin setup

The installer unpacks Myelin into ~/.myelin and leaves one launcher in ~/.local/bin. It never uses sudo and it does not install Node for you. Run it again later to upgrade. On Windows the same layout lives under %LOCALAPPDATA%\Myelin, and the installer adds it to your user PATH.

Then, inside a project, run myelin setup. It reads your package.json, copies the matching ledgers into .myelin/, and adds a short block to AGENTS.md or CLAUDE.md so your agent runs the rules before it writes and lint after. Run it again whenever your dependencies change; it replaces its own block and touches nothing else. If something looks wrong, myelin doctor will say what.

the ledger

A ledger is one short text file of hard rules for one library at one version. Each rule is a regular expression plus the sentence that explains the fix. This is the three.js ledger with its long lines trimmed.

!Ban. Must never appear in the output.
+Require. Must appear in the output.
~Preference. Read by the model, not checked.
=Fact. Versions and budgets. Read, not checked.
$Snippet. Copy-exact code a rule can point to.

Before the model writes, myelin gate three prints the rules as plain text, or your agent reads the file directly. After, myelin lint three src/ runs every ban and require against your files and exits 1 on any violation. In a chat window with no tools, paste the output of myelin gate three --all into the prompt. The full grammar is in docs/SPEC.md.

limits

Myelin is deliberately small. These are its edges.

It reads text, not meaning. Rules are regular expressions. They catch stale names and patterns. They cannot judge logic, types or intent, so keep your tests and your type checker.

Clean is not correct. A pass means no known-stale pattern was found. It does not mean the code runs.

The lift is measured on three.js only. Across 24 agents and two model families, 7 of 8 unguided runs wrote a stale three.js API and 0 of 16 guided runs did. The other eighteen ledgers have detection benchmarks but no agent runs yet. A well-written prose skill matched the gate on stale-API rate; the gate's edge is that the same file verifies the output.

Comments can trip it. A banned token inside a comment can fire a rule. Ledgers can set comments skip to blank comments out first, and so far only the three.js ledger does.

Every ledger is pinned to one release. Each targets a single version and a research date. Check the = version line before you trust one on a newer major.

It is narrow on purpose. The three.js ledger covers the WebGPU and TSL path, not WebGL-only projects. unless lifts a ban for a whole file, not for one match. There are no globs or severities yet.

It only constrains output. A ledger cannot grant permissions, run commands or change instructions, and readers ignore any line that tries. Load ledgers only from your own project or a source you trust.
